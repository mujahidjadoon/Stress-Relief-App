The Relaxation App is a web application designed to help users reduce stress and find relaxation through various activities.  It is built using Python and the Streamlit framework, providing a user-friendly and interactive experience.FeaturesWelcome Page: Greets the user and prompts them to enter their name.Activity Selection: Presents the user with a choice of relaxation activities:Deep Breathing: Provides on-screen instructions and a visual guide for a deep breathing exercise.Listen to Music: Plays relaxing music. Users can choose from default music or upload their own audio files.Guided Meditation: Plays a guided meditation audio.  Users can upload their own guided meditation audio.Nature Sounds: Plays calming nature sounds.  Users can upload their own nature sound audio.Custom Audio Upload: Users can upload their own .mp3 or .wav audio files for the "Listen to Music", "Guided Meditation", and "Nature Sounds" activities.Responsive Design: The application is designed to be responsive and user-friendly.Technologies UsedStreamlit:  A Python framework for building interactive web applications.Pygame:  A Python library for multimedia applications (used for audio playback).PIL (Pillow):  A Python library for image processing (used for displaying images).Setup InstructionsFollow these steps to get the Relaxation App running on your local machine:PrerequisitesPython: Python 3.7 or later must be installed.  Download it from python.org.Git: Git must be installed to clone the repository.  Download it from git-scm.com.InstallationClone the RepositoryOpen a terminal or command prompt.Navigate to the directory where you want to store the project:cd <your_desired_directory>
Clone the repository from GitHub:git clone <repository_url>
(Replace <repository_url> with the actual URL of the GitHub repository.)Navigate to the Project DirectoryUse the cd command to enter the project directory:cd relaxation-app
Create a Virtual Environment (Recommended)Create a virtual environment to isolate the project's dependencies:python -m venv venv
Activate the virtual environment:On Windows:venv\Scripts\activate
On macOS/Linux:source venv/bin/activate
Install DependenciesInstall the required Python packages:pip install -r requirements.txt
If a requirements.txt file is not included, install the dependencies manually:pip install streamlit pygame Pillow
Download Media FilesThe application uses audio and image files.  You'll need to obtain these and place them in the same directory as main.py.Audio:The application uses  relaxing_music.mp3,  guided_meditation.mp3, and  nature_sounds.mp3.  You can replace these files with your own audio files.  Ensure they are in .mp3 or .wav format.  If you do not have these, you can find relaxing music on Pixabay.Image:The application uses  nature_image.jpg.  Replace this with your own image.  Ensure it is a  .jpg  file.A default image is shown in the immersive artifact.Video:The application uses meditation_video.mp4.  Replace this with your own video.  Ensure it is a .mp4 file.Run the ApplicationMake sure your virtual environment is activated.Run the Streamlit application:streamlit run main.py
The application will open in your web browser.UsageWelcome Page: Enter your name and click "Start" to begin.Activity Selection: Choose from the following relaxation activities:Deep Breathing: Follow the on-screen instructions and visual guide.Listen to Music: Play relaxing music.  You can upload your own audio file.Guided Meditation: Play a guided meditation session. You can upload your own audio file.Nature Sounds: Play calming nature sounds.  You can upload your own audio file.Audio Playback: For activities that involve audio, use the Play, Pause, and Stop buttons to control playback.Back Button: Use the "Back" button to navigate to the previous page.
